# Integration of Mathematical Calculations with a Chat Completion System using LLM Function-Calling

## AIM

To design and implement a Python function to calculate the volume of a cylinder and integrate it with a Chat Completion System using Large Language Model (LLM) Function-Calling.

## PROBLEM STATEMENT

To develop a Python-based application that calculates the volume of a cylinder using its radius and height. The application uses an LLM chat completion system to understand the user's input, call the appropriate Python function, perform the mathematical calculation, and generate the final response.

**Formula:**

V = π × r² × h

Where:
- V = Volume of the cylinder
- r = Radius of the cylinder
- h = Height of the cylinder
- π = 3.14159

## ALGORITHM

1. Import the required Python libraries.
2. Initialize the Groq API client using the API key.
3. Define a Python function to calculate the volume of a cylinder.
4. Create a JSON schema for the function with radius, height, and unit parameters.
5. Get the user's input through the LLM chat completion system.
6. Extract the function arguments generated by the LLM.
7. Execute the Python function to calculate the cylinder volume.
8. Send the calculation result back to the LLM.
9. Generate and display the final response.

## COMPLETE PROGRAM

```python
# Install the required library:
# pip install groq

import os
import json
import math
from groq import Groq

# Initialize Groq client
client = Groq(
    api_key=os.environ.get("GROQ_API_KEY")
)

# Function to calculate cylinder volume
def calculate_cylinder_volume(radius, height, unit="units"):
    volume = math.pi * radius * radius * height

    return {
        "radius": radius,
        "height": height,
        "volume": round(volume, 2),
        "unit": unit
    }

# Define function schema
tools = [
    {
        "type": "function",
        "function": {
            "name": "calculate_cylinder_volume",
            "description": "Calculate the volume of a cylinder",
            "parameters": {
                "type": "object",
                "properties": {
                    "radius": {
                        "type": "number",
                        "description": "Radius of the cylinder"
                    },
                    "height": {
                        "type": "number",
                        "description": "Height of the cylinder"
                    },
                    "unit": {
                        "type": "string",
                        "description": "Measurement unit"
                    }
                },
                "required": ["radius", "height", "unit"]
            }
        }
    }
]

# Get user input
user_input = input("Enter radius and height of cylinder: ")

# Send request to LLM
messages = [
    {
        "role": "user",
        "content": user_input
    }
]

response = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=messages,
    tools=tools,
    tool_choice="auto"
)

# Check for function call
response_message = response.choices[0].message
messages.append(response_message)

if response_message.tool_calls:
    for tool_call in response_message.tool_calls:

        function_name = tool_call.function.name
        function_args = json.loads(
            tool_call.function.arguments
        )

        if function_name == "calculate_cylinder_volume":

            result = calculate_cylinder_volume(
                radius=function_args["radius"],
                height=function_args["height"],
                unit=function_args["unit"]
            )

            # Send function result back to LLM
            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": json.dumps(result)
            })

    # Generate final response
    final_response = client.chat.completions.create(
        model="openai/gpt-oss-120b",
        messages=messages
    )

    print("\nFinal Answer:")
    print(final_response.choices[0].message.content)

else:
    print(response_message.content)
```
